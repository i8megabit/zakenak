# Тестирование Zakenak

Этот файл описывает базовые проверки проекта.

## Запуск тестов

```bash
cd tools/zakenak
go test ./...
```

## Покрываемые модули
- загрузка конфигурации
- менеджер состояния
- настройки сборки
- генерация конфигурации Kind

Тесты не требуют сторонних сервисов и выполняются быстро.

## Интеграционное тестирование с Minikube
Для проверки работы Zakenak в условиях, близких к реальным, используется отдельный workflow `integration.yml`. Он поднимает однонодовый кластер Minikube на GitHub Actions раннере и выполняет деплой с помощью Zakenak.

Запустить тесты можно вручную через вкладку *Actions* либо при push в ветки `main` и `develop`.

В рамках workflow выполняются юнит-тесты проекта и деплой тестового кластера.
